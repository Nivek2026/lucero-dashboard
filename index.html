Conexión con GitHub (una sola vez)

Abrir pestaña Actions
Sin token el dashboard solo se puede ver. Cómo crearlo:
  1. GitHub → tu foto → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → elige solo este repositorio.
  3. Permissions → Repository permissions: Actions: Read and write y Contents: Read and write.
  4. Genera el token, cópialo y pégalo arriba. Se guarda solo en este navegador. No lo compartas.
